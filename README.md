## Wenqi Cheng

Data scientist in advertising measurement. I work on experiment design, causal inference, and the pipelines that make an analysis reproducible — mostly A/B and advertiser-randomized tests, difference-in-differences, and metric definitions that survive review.

Lately most of my building is **LLM agents that do analytical work**: agents that answer data questions against a warehouse, check their own numbers before reporting them, and get evaluated against a graded test set instead of vibes.

### Public work

**[vocab](https://github.com/wenqicheng/vocab)** — a vocabulary agent for Claude Code and Codex. Paste a sentence you're reading; it finds the one word worth learning, explains it in your own context, and quizzes you on a spaced-repetition schedule. It also reads your saved words to infer your level, and adjusts what it bothers explaining. Built it for myself, published it once it was good enough to hand to a friend.

**[SQL_runner](https://github.com/wenqicheng/SQL_runner)** — a 2019 Python library that ran SQL as code across four warehouses, with placeholder substitution for recurring jobs and QA checks built into the run.
